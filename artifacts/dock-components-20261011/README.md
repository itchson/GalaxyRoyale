## Measured cost and limits

`cpu-benchmark/` retains 43,200 actual optimized native render extractions at
the frozen dock commit `7d3673e` (integrated as `54653ba`). This predates the
later Profile 7 changes and is not presented as timing the final browser.
Cold callback cost is 25.51-27.03ms; warm median added extraction cost is
0.504-0.529ms. Maximum measured world output is 38,115 quads/117 transforms.
These are CPU measurements; GPU upload/draw, browser, RSS, physical phones and
30-minute soak were not measured. Cold asset prewarming remains a follow-up.
