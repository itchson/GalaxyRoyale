## Packed contract and API

`engine_core::Surface::new(normal:[f32;3], emission_mask:u8) -> Result<Surface,&'static str>` validates finite nonzero inputs and robustly oct-encodes all hemispheres without magnitude overflow/underflow. Local axes: +X right, +Y down, +Z viewer. `Surface` is four bytes. `packed()` has low7 bits zero, octX8 in7..14, octY8 in15..22, emissionMask8 in23..30 and enabled bit31. `normal()` returns the decoded normalized vector, `emission_mask()` returns the linear byte multiplier, `from_cell_word()` strips the transform slot only when enabled. A missing map emits exactly zero upper bits; it has no per-cell allocation.

The mask scales **existing object material emission**, not standalone energy or an automatic light. 255 preserves authored emission,0 blocks it. Normal-only opt-in maps should use255. Root's shader must first decode existing soft negative-emission conventions, then multiply only for enabled maps. Legacy cells must remain unchanged. Opt-in flat +Z quantizes to oct[128,128], with the small oct8 tilt; absence is exact legacy behavior.

`PixelInstance::transform_slot() -> usize` masks the low7 bits; `surface() -> Option<Surface>` inspects metadata. The 16-byte cell and32-byte transform streams, local coordinates, RGBA, materials and128-slot batching remain unchanged. All engine_core examples/tests/source CPU table lookups now use this helper. Root must update external game_core/game_web/proof consumers before opting assets in; the previous whole-word lookup is incompatible with enabled metadata. No old/new shader bundle compatibility is claimed.

`PixelBody::set_surfaces(&[Surface], maximum_cells)` checks multiplied dimensions, existing canvas length, exact field length and budget **before allocation**, retaining prior data on rejection. Optional boxed maps are deep-cloned with the body; `clear_surfaces()` releases them. `surfaces()` exposes the stable full canvas and `surface_index()` filters occupancy. Imported Surface is already validated by the constructor. Holes, alpha-zero occupancy, swept collision, destruction, connected components and damage returns use the original packed colors/occupancy only.

Body extraction now packs the optional Surface by original row-major index while preserving its existing color callback. `FrameBuilder::push_cells_affine_surface_material` takes `(Vec2,RGBA,Option<Surface>)` for streamed subobjects without a body clone or another GPU stream. PixelRig retains the actual damaged body's index/field when partitioning live cells, with existing color/charge/hit animation. Current rig placements are translations, so original authored local normal axes are preserved. A future rotated/reshaped part must supply normals in that part's local coordinates.

`Surface::world_normal(AffineTransform)` is a portable CPU oracle: inverse transpose of `diag(A,sqrt(abs(detA)))` on the **full composed basis**, followed by normalization. Uniform scale preserves the appearance; nested nonuniform rotation/shear/reflection are represented correctly. Translation is irrelevant. Singular/nonfinite bases return None. f64 intermediates preserve valid extreme finite f32 bases without determinant overflow/underflow. This oracle does not claim all such extreme geometry is representable by a GPU shader; Root must define its f32 relative-basis guard without imposing an absolute minimum quad size. Shader transformation occurs once; do not bake world normals then transform them again.

## Integration limits

Root still owns matched WGSL/light depth, actual native compilation of Art's authored PAN semantic sidecar, asset lookup/registration, external slot-index updates, both renderer builds and real visual review. Material metadata is currently absent from co-op body pages/signatures; deterministic native asset reconstruction may restore registered fields, but this portable engine change alone does not prove guest material parity. No per-pixel ECS entities, new physics state, RNG, progression, save fields, independent lights or dependency were introduced.
