## Patch only the three consumers and focused tests

1. **wire.ts — descriptor and distinct full page.** Add `wake_fx` to the snapshot allowlist. On own-property presence, require an exact one-key object with integer `points`0..192; omission means zero, null/undefined/extra keys/missing key reject. Split common session/tick/revision checks from geometry offsets. Detect an own `points` variant first, then require exactly `session,tick,revision,points`; reject mixed geometry keys rather than falling through to cells. Each point requires exactly `slot,epoch,born_tick,position,life`: slot integer0..7, epoch nonzero u32, birth u32<=page.tick, sorted slot/birth with strict unique keys, at most24/slot and192 total. Shape-valid empty pages are diagnostic DTOs; receiving state later rejects them because zero headers require no page.
2. **wire.ts — scalar and byte checks.** Life raw finite >0<=`Math.fround(3.4)` and converted finite positive f32 within that maximum; coordinates raw and f32 finite within±1,000,014. Do not demand raw equality to fround. Count serialized UTF-8 page bytes<=32768 for value/encode paths. Existing frame limit65536 stays. For strict incoming raw-page parity, `decode` must also measure the actual top-level `payload` span in validated body-frame text for this points variant, including internal whitespace/number spelling, before returning it. A compact normalized value check cannot enforce this raw limit. Use a small bounded top-level JSON field-span helper after `JSON.parse`/shape validation, tracking strings/escapes/nested depth and decoding key spelling; measure UTF-8, not JS characters. Reject duplicate payload keys or otherwise measure the exact last-key span adopted by JSON.parse. Do not use a regex that mistakes string/nested/escaped `payload` keys for the top-level field. No generic negotiation or schema framework is needed.
3. **controller.ts — one capture flag and one receiving flag.** Read advertised count through one small helper on an already validated header. Initialize `Capture.wakeAppended` and `Receiving.wakeReceived` false for positive count, true for zero/omitted count. `Counts.body_pages` remains cell geometry only. After final entity page and before any cells/end, `#append` makes one `wake_page` batch call with session/acquisition/revision, validates the page and exact session/tick/revision/count/roster, pushes one existing `body` Piece, and marks appended. A zero capture makes no call/page. Reuse the existing immutable header/shared pieces; do not acquire a second world or append once per peer.
4. **controller.ts — positively identify cells when skipping.** The existing send shortcut tests body/non-entities; change it to `Array.isArray(record(piece.payload).cells)`. Only cells may use a row body signature to advance peer index without sending. Both entity and Wake pages always send, including all-body-cached captures. Capture-wide row body skipping likewise affects only later cells; do not let it reach `publication-end` before the one required Wake append. Preserve two pieces/peer/frame, four serializations/frame, 1MiB and80 frames/peer/sec, buffered limit,30-second barrier and retry index behavior.
5. **controller.ts — branch before cells and commit only complete state.** In `#page`, after exact publication tokens, distinguish `points` before entities/cells. Require positive advertised count, exact array count, no prior Wake page, exact current roster slot+epoch, and the producer's entity-complete/Wake-before-cells order. Do not change bodyPages/bodyOffset/lastCell/bodyIndex/row caches for points. Call the existing ReplicaPort.page; mark received only after true. Add the required Wake flag to `#commit` alongside existing entities/cells checks. No successful commit means no ACK, cache promotion or connected transition. An unexpected zero/duplicate/missing page fails closed. Keep complete-set equality/deadlines native; no JS trail cache, timers, pose reconstruction or birth replay.
6. **wasm-ports.ts — third page delegate.** Keep existing `validatePayload`, ownership, acquisition/revision and request/unit-response checks. Route own points array to `replica_wake`, entities to `replica_entities`, cells to `replica_body`; unknown/mixed shapes have already rejected. Same `ReplicaPort.page(Json)` API and65536 request bound work. Do not reset ownership token after a rejected page/commit; end still releases through the actual native end request and retains blocked restoration if end fails.

No new transport kind, channel, body-query form, Main API, browser renderer context, saved state, gameplay loop or capability negotiation is required. New strict bundles must match; old exact-shape consumers reject modern metadata. Native host author uses ordinary ID5 only. Existing different projectile/whole-edge bounds are separate known concerns, not part of this patch.
