## Camera and uniform composition

Stars use bounded field-local cells, with size in their parent basis; they avoid dividing absolute ±1M positions by tiny pixel size. Motifs retain cached local bodies and compose child transforms beneath a seeded rotated/scaled parent. The parent encodes `origin + unshaken_interpolated_camera * (1-factor)` once. The shared renderer subtracts its actual shaken render camera from each packed affine translation on CPU before local multiplication. This leaves the desired parallax plus presentation shake. Extraction receives the eased world viewport from `Game.set_viewport`; it does not divide by zoom again.

Both graphics backends compile the same WGSL/layout. Actual Naga validation succeeded. `Globals` has a 288-byte span: camera offset0, ambient offset16, lights offset32, with eight 32-byte lights. CPU `UNIFORM_FLOATS=72`, both world/UI buffer allocations, binding minimum size and uploads match. The transform table remains 4096 bytes for 128 records. Growth recreates both world and UI geometry bind groups. Per-frame scratch clears before packing; current draw counts reference current batch contents, not old capacity.

The world projection uses the actual world extent and biome ambient. The UI projection uses the logical base viewport, a neutral `[1,1,1,0]` ambient and no light sources. Both pass the same CPU camera-relative affine table. New ambient multiplication is inside `response>0`; cached cosmic bodies, streamed stars, semantic panels, font letters and controls use zero response/emission. Their authored colors are therefore unaffected by biome grading. Lit receivers retain the existing 0.12 dim/0.3 emission treatment, with the new bounded 0.9..1.1 grade only on their receiving material. Unknown/Haven biomes use neutral grading.

Reduced Motion freezes motif child geometry/colors/opacities and star twinkle at time0; seeded parent rotation remains fixed, and camera parallax still responds to travel. Browser shake is separately gated off when reduced. An invalid scene returns before append; finite practical camera/extents are clamped. Field density/color corner samples are computed once per field extraction and shared across its 32 candidate stars; they are not a new persistent per-frame cache. Cached art bodies initialize lazily once.

## Presentation limits and remaining integration gates

The peer's actual software contact sheet was inspected: quiet sparse Haven; distinct spiral, torn filament and broken nova silhouettes; reduced geometry coarser by design. These are software packet previews with no composed actors/Scar/hostile shots/UI. At min zoom the 0.70-world star cell is 0.42 logical pixel and may disappear for some subpixel positions. Actual backend/display contrast and Mote/boss cue readability must be assessed in Root's normal GPU/GL captures and human tuning.

The renderer clear is `[0.0001,0.00011,0.00014]` in a linear `Rgba8Unorm` logical target. All channels are below half of one 8-bit step and consequently quantize to black; it should not be described as a measured subtle colored wash. That is consistent with the requested dark space. Any future distinct nonzero base wash should use values representable in this target and verify the actual output rather than software float previews.

Uniform/shader validation does not execute the backend. Pending gates are normal dual-backend initialization after the 288-byte change, seeded near/far moving views and zoom changes, composed lit actors/unlit UI, reduced-motion transitions, actual responsive six-tab/scroll/settings layout, and physical target phones. Native HUD worker changes need their own final source/geometry review.
