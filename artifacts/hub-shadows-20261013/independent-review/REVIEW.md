## Source findings

1. **Current occupancy and ownership.** `Game::extract_hub_shadow` borrows the actual local player `Motion/Actor/PixelBody`, excludes dead/nonplayer, co-op, material diagnostic and out-of-footprint cases, and uses the same positional/shortest-heading interpolation and `actor_transform` as the actual actor extraction. Height is a presentation constant, not saved state or authority. `PlanarShadows::set_body` rebuilds an alpha>=128 occupancy mask from current cells; removed cells disappear. No pristine body, fine overlay, exhaust, shield, particle or HUD enters the caster. The coarse silhouette is an explicitly limited approximation of the healthy authored coarse+fine art.

2. **Geometry and rebasing.** The point-light intersection uses the receiver/caster/source height ordering and applies the inverse complete affine. Shader descriptors form the inverse in f64 after subtraction of the renderer's final presentation camera, including shake. Geometry and light positions use the same camera-relative space. Zoom affects projection, not plane height, source offsets or mask coordinates. Native tests cover fractional scale, shear, reflection and translated geometry. The fixed160 admission radius is conservative for current main-hub corners (~136) and current48-grid starter at scale0.7 or32-grid campaign hull at scale1; it is not a general arbitrary128-cell/new-scale culling proof.

3. **Actual receivers and art preservation.** The native256 adapter tags only occupied role0(deck) and role1(alloy), plane0, while an active native caster exists. Screens/signals, facilities, background/parallax objects and UI retain zero flags. Empty pixels have no geometry. Existing dock admission rejects before appending or consuming budget; the Game clears its caster before the legacy-home fallback. The scoped adapter test compares exact existing pixel/RGBA/affine/material packets:28,549 cells,16 transforms,25,919 receiver cells. No receiver sprite or extra shadow quad is added.

4. **Lighting and emissions.** Beacon construction is factored without changing its values. Exact raw light-key equality is resolved only among the same finite-filtered, clamped, first-eight sources used by lighting uniforms; unrelated, rejected or truncated sources cannot acquire a beacon shadow bit. Only selected reflected-light energy is occluded. The bounded contact term attenuates reflected/ambient energy while adding authored emission independently. Screen/signal groups are excluded entirely. Default height/flags retain the legacy shader path, including existing soft-particle coverage. The current shader deliberately uses flat per-cell coordinates, consistent with one shaded color per occupied pixel; it is not a continuously shaded 3D hull.

5. **ABI and packing.** Pixel instances remain16 bytes, affines32 bytes. Typed ObjectMeta8 bytes is separate: two records form each std140 vec4-u32 pair. Blocks are Globals304, transforms4096, objects1024, descriptors400 and masks16384 bytes. Dynamic offsets are ordered for transform/object bindings, each stride divisible by256. Descriptor count is currently one; fixed eight capacity is not eight-caster runtime support. Native slot127/split/nested-scope reuse checks preserve default metadata before/after scopes and on reused batches. Renderer table padding fills absent metadata and explicitly forces all UI entries to zero; upper Surface bits continue to be masked when selecting slots.

6. **Clearing and caching.** Frame clearing resets active shadow/caster/light and metadata scopes while preserving allocated storage. Renderer writes a descriptor header on every draw, including zero on deactivation. Cached old mask bytes cannot be reached with zero count. Fresh renderers upload active masks because their cache starts absent. Mask buffer identity does not change during table growth; geometry groups are rebound to grown transform/object buffers. Stable-zero metadata frames skip uploads; transition frames clear previously active object metadata. Native/portable tests prove buffer shapes and CPU scope behavior; actual GPU stale-state and recovery behavior are still unmeasured.

7. **Costs and limits.** CPU extraction clears slot0's2,048 bytes and scans current hull occupancy every admitted extraction. Renderer compares the entire16KiB mask each admitted draw, writes400-byte descriptors every draw, copies/uploads changed masks, and pads object tables. Each tagged fragment currently evaluates four source taps twice, for contact and direct lighting. One caster and one selected light are bounded, but no frame-time percentile, eight-caster cost, memory soak or mobile budget is established. This is a planar receiver/occluder model, not mesh self-shadowing or volumetric shadows.
