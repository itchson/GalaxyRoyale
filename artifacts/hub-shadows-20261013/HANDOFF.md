## Runtime contract

- One living local solo RAICHO, its current authoritative packed body and interpolated pose, presentation height6. Admission is restricted to a visible main hub and a ship center within160 world units. Co-op sessions and the dedicated material diagnostic are excluded. Rejecting the native256 home adapter clears the active caster. Hidden/dead/far/empty/invalid body and subsequent cleared frames cannot retain active descriptors.
- Actual opaque occupied cells (alpha>=128) populate slot0 in a fixed128-row-stride bitmask. Removing body cells removes their bits on the next extraction. No pristine template, alpha-zero cell, collision, ability, reward, save, RNG, vertical authority or network-page change is introduced. The retained collision body's coarse field supplies the silhouette; the fine96 visual overlay does not contribute separate micro-silhouette geometry in this increment.
- The existing nearest beacon constructor is factored without changing its light values: home position[0,0], radius120, cyan[.2,.85,.92], intensity .48+sin(cosmeticTime*1.2)*.08; existing light height42. A typed exact key must occur within the renderer's actually finite-filtered/clamped first8 lights. A different nearest beacon, truncated/missing home light or material scene lights disable shadow descriptors. No new lamp pose, lighting source or color heuristic.
- Only main native256 dock role0(deck) and role1(alloy) occupied quads receive shadows, plane height0. Role2(screens)/3(signals), UI, distant/parallax art, floating facilities and empty space stay outside the receiver flag. The main artwork remains28549 cells/16 transforms, with its existing corporation recolors, lamp poses and frozen reduced-motion animation. The adapter packet test proves existing local cells/RGBA/transforms/materials are identical.
- Receiver-fragment ray intersects the actor plane at `R+(zc-zr)/(zl-zr)*(L-R)`, then applies the full inverse composed affine and checks real cell occupancy. The inverse is computed in f64 after camera rebasing before finite f32 packing. The guard rejects relatively degenerate bases, nonfinite fields, out-of-range dimensions/heights; no minimum pixel size or zoom quantization is added.
- Four deterministic area-source offsets(+/-1.5 world units) provide a small penumbra. Selected reflected light is attenuated by visibility; the separate reflected/ambient term receives at most18% contact attenuation. Authored self emission stays independent. Mapped actor normal lighting uses the light's relative height above the actor, and existing normal/luminance Surface bits remain intact.

## Portable layout and costs

PixelInstance remains16B; GpuTransform remains32B. Optional ObjectMeta is8B per transform and allocated only when a nondefault group is extracted; scopes retain nested values and do not clear legacy/default particle caches unnecessarily. Batch metadata and mask storage are reused after clearing. Production extraction borrows PixelBody; it does not clone bodies, colors or frames.

GPU blocks are separate: Globals304B, transform table4096B, object table1024B(dynamic offset, vec4-u32 pairs), caster descriptors400B(header16 +8*48), occupancy16384B(exactly WebGL2's declared uniform-block limit; no header hidden inside). Shared Naga30.0.1 validated these exact spans with empty optional capabilities, then emitted actual ES300 WebGL vertex/fragment source with3 reflected uniform blocks each. Buffers and scratch tables are reusable and grow only with existing batch capacity.

Initial runtime count is1 even though mask/descriptor capacity is8. CPU mask rebuild clears slot0's2048B and scans the current field. The renderer compares the full16KiB mask each admitted frame and uploads/copies it only when different (or on the fresh renderer). Descriptor writes are400B every draw, including a zero header on deactivation. Object-table writes skip stable zero-state frames; CPU table padding is still performed. UI uses forced-zero metadata. Current WGSL evaluates four taps twice per tagged fragment (contact and direct lighting); this cost is explicitly pending measurement. No eight-caster, mobile, percentile, memory-soak or GPU-time performance claim.
